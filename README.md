# 🎀 Memory Match Game

A cute pastel-themed Memory Match Game built with Angular.

## ✨ Features

- Flip cards to find matching pairs.
- Track moves and matched pairs.
- Timer to track your playing time.
- Restart the game whenever you want.
- Responsive design with a cute pastel theme.

## 🛠️ Tech Stack

- Angular
- TypeScript
- HTML
- CSS

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Priyanka-Mohanty26052001/memory-match-game.git
   ```

2. Navigate to the project folder:

   ```bash
   cd memory-match-game
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   ng serve
   ```

5. Open `http://localhost:4200/` in your browser.
